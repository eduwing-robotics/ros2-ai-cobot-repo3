## S0–S4의 증거 기준

| 단계 | 화면에서 확인할 것 | 성공으로 말할 수 있는 범위 |
|---|---|---|
| S0 관측 | 글로벌 카메라 정합, 로봇 연결·조종권·정지 상태 | 작업 셀의 현재 입력이 신선하다 |
| S1 이동 | TurtleBot 목표 이동과 정차 | 팔 명령 전에 AMR이 정지했다 |
| S2 탐색 | 손목 RGB-D의 거치대·총알 검출 | 현 위치에서 파지 계획 입력을 얻었다 |
| S3 검토 | 고스트 경로, IK·작업영역·접촉 결과 | 실기 명령 없이 계획을 먼저 검사했다 |
| S4 실행 | 접근→사전 성형→파지→들기와 최종 HOLD | 지정 셀에서 집기·들기를 한 차례 완주했다 |

## 표현 규칙

- `실기`는 실제 장치가 움직인 자료에만 붙인다.
- `실기 화면 · AR`은 실제 영상 위 가상 정보를 겹친 자료다.
- `렌더`와 `시뮬레이션` 통과를 실기 성공으로 바꾸어 쓰지 않는다.
- GIF 배속은 편집 정보다. 실제 로봇 속도나 사이클 시간을 뜻하지 않는다.
- 각 파생 파일의 원본명과 배속은 [source-manifest.json](../assets/media/fr5/source-manifest.json)에 기록한다.
