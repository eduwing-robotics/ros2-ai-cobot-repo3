## 빠른 실행

```bash
~/sam3_env/bin/python scripts/run_sam3_depth.py \
    --prompt bullet --threshold 0.4 --display \
    --pose --pose-json picks.json \
    --roi "75,35,505,395" --exclude "145,195,300,245"
```

탄두/탄피 × 눕힘/꽂힘 4가지를 구분하고, 집기 좌표를 `picks.json`에 낸다. 종료는 창에서 `q`.
영역 값의 의미와 조정 방법은 [운용설정.md](운용설정.md) 참조.

## 핵심 요약

**색도 안 쓰고, 분류에 깊이도 안 쓴다.** SAM 3에는 형태 프롬프트 `bullet` 하나만 주고,
분류는 실루엣 비율과 윗면 명암으로 한다. 깊이는 집기 좌표에만 쓴다.

```
종횡비 < 2.2  →  꽂힘 :  중심−중간 밝기 ≥ 10 → 탄피 (평평한 뇌관) / 미만 → 탄두 (둥근 돔)
종횡비 ≥ 2.2  →  누움 :  테이퍼 ≥ 0.15 → 탄두 (물방울) / 미만 → 탄피 (원통)
```

전부 물체 내부에서 계산하는 **비율과 상대 밝기**라 카메라 거리·각도·배경·트레이가 바뀌어도 유지된다.
깊이 높이로 판정하던 초기 방식은 배치가 바뀔 때마다 무너졌다(자세한 사례는 파이프라인 문서 0장).

색 기반 프롬프트(`gold cylinder`, `silver bullet`)는 조명·도금이 바뀌면 무너진다. 회색조로 변환해 돌려보면 바로 드러난다.

## 환경

- 오버레이 venv `~/sam3_env` — lerobot 환경의 torch를 상속만 하고 건드리지 않는다
- transformers 5.16.1, torch 2.11.0+cu130 (sm_120)
- `facebook/sam3` 가중치는 gated. 웹 게이트 승인과 CLI 인증이 별개 절차다

## 알려진 한계

- 속도 1.3 FPS. 트레이에서 하나씩 집는 작업엔 충분하다(정지 장면이라 변화 게이팅으로 추론이 거의 안 돈다).
  컨베이어처럼 흐르는 대상이면 부족하므로 그때 YOLO 학습을 고려한다
- 임계값은 물체 내부 비율이라 배치 변화에 강하지만, 부품 규격이 바뀌면 재측정이 필요하다
- 임계값을 클래스당 2~3개 표본으로 잡았다. 조명·자세를 바꿔가며 더 모아야 한다
- SAM 3 파인튜닝은 최소 16GB VRAM 필요라 이 PC에서 불가
