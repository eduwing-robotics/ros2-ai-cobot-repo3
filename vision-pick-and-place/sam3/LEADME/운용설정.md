# 운용 설정 — 현재 배치 기준

> 확정일: 2026-09-08
> 이 문서는 **현재 카메라·설비 배치에 묶인 값**을 기록한다.
> 배치를 바꾸면 5장의 재측정 절차를 따른다. 원리와 실측 근거는 [탄약-검출-파이프라인.md](탄약-검출-파이프라인.md) 참조.

---

## 1. 실행 명령 — 이대로 복사해 쓴다

```bash
~/sam3_env/bin/python scripts/run_sam3_depth.py \
    --prompt bullet --threshold 0.4 --display \
    --pose --pose-json picks.json \
    --roi "75,35,505,395" \
    --exclude "145,195,300,245" \
    --save-every 60 --out-dir depth_live
```

종료는 창에서 `q`. 집기 좌표는 `picks.json`에 매 프레임 갱신된다.

검출만 확인할 때는 `--display` 대신 `--max-frames 1 --dump` 를 쓴다.

---

## 2. 영역 설정 (640x480 컬러 프레임 기준)

| 항목 | 값 | 의미 |
|---|---|---|
| `--roi` | `75,35,505,395` | 트레이 2개 + 오른쪽 지그. 중심이 밖이면 버린다 |
| `--exclude` | `145,195,300,245` | 트레이 사이 금속 조인트. 탄피(꽂힘)로 오검출되던 자리 |

ROI 밖으로 빠지는 것들: 오른쪽 금속 브래킷, 아래 클램프, 위쪽 수직봉.

**물체를 놓는 위치**

- 꽂힌 탄두·탄피 → 왼쪽 트레이 2개
- 누운 탄두·탄피 → 오른쪽 흰 지그 위

---

## 3. 판정 임계값

| 옵션 | 값 | 실측 근거 |
|---|---|---|
| `--pose-aspect` | 2.2 | 꽂힘 1.11~1.73 / 누움 2.78~5.34 (마진 1.05) |
| `--center-bright` | 10 | 탄두 −15.5~−6.1 / 탄피 +27.6~+28.2 (마진 34) |
| `--taper-th` | 0.15 | 탄두 0.19~0.25 / 탄피 0.06~0.11 (마진 0.09) |
| `--min-height-mm` | 1.0 | 고정대 조인트 −9mm / 실물 4~45mm (마진 10) |
| `--threshold` | 0.4 | SAM 3 검출 신뢰도 |

전부 기본값이므로 명령에 따로 쓰지 않아도 된다. 위 실행 명령에 없는 이유다.

**`--taper-th` 만은 배치에 묶이지 않는다.** 거리 337·410mm, 기울기·배경이 다른 네 배치에서 같은 값이 재현됐다.
나머지 셋은 현재 배치 기준이다.

---

## 4. 오검출이 생기면

순서대로 시도한다.

1. **위치를 확인한다.** 고정 설비 위라면 `--exclude "x1,y1,x2,y2"` 를 하나 더 추가한다 (여러 번 지정 가능)
2. **ROI를 좁힌다.** 작업 영역 밖이면 `--roi` 를 조정한다
3. **높이를 본다.** `--dump` 로 실행해 해당 물체의 높이를 확인한다. 음수거나 1mm 미만이면 `--min-height-mm` 이
   이미 거르고 있어야 한다. 깊이가 `nan` 이면 이 검사가 건너뛰어지므로 1·2번으로 막아야 한다
4. **크기로 거른다.** `--min-area` / `--max-area`

좌표는 저장된 `depth_live/d_*.png` 를 이미지 뷰어로 열어 픽셀 위치를 읽으면 된다.

---

## 5. 배치를 바꿨을 때 — 재측정 절차

카메라 위치·각도, 트레이 종류, 부품 규격이 바뀌면 다음을 다시 잡는다.

**다시 재야 하는 것**: `--roi`, `--exclude`, `--center-bright`
**유지되는 것**: `--taper-th`, `--pose-aspect` (비율 지표)

절차:

1. 네 종류(꽂힌 탄두·탄피, 누운 탄두·탄피)를 **각각 2개 이상 한 화면에** 놓는다. 손은 화면 밖으로
2. 한 프레임 찍어 번호를 매긴다

   ```bash
   ~/sam3_env/bin/python scripts/run_sam3_depth.py --prompt bullet --max-frames 1 --dump --save-every 1
   ```

3. 어느 번호가 무엇인지 확인한 뒤, 클래스별 종횡비·명암·테이퍼 분포를 보고 경계를 두 분포 사이에 둔다
4. 새 값을 이 문서에 기록한다

**주의**: 표본이 클래스당 2개로 잡은 값이다. 실제 운용 전에 조명과 자세를 바꿔가며 더 모아 마진을 확인하는 것이 좋다.
`scripts/autolabel.py` 가 물체를 재배치할 때마다 자동 촬영하므로 표본 수집에 쓸 수 있다.

## 6. 집기 좌표 (`picks.json`)

```json
{
 "frame_id": "camera_color_optical_frame",
 "plane_mm": 334.0,
 "objects": [
  {"cls": "탄피(꽂힘)", "pos_mm": [22.5, -3.5, 269.0], "yaw_deg": null,
   "height_mm": 45.4, "approach": "vertical", "pick_order": 0, "score": 0.79}
 ]
}
```

- `pos_mm` — **카메라 좌표계** (X, Y, Z) mm. 로봇 좌표로 쓰려면 핸드아이 캘리브레이션이 필요하며 현재 없다
- `yaw_deg` — 물체 주축 각도. 꽂힌 물체는 회전 대칭이라 `null`
- `approach` — `vertical`(수직 하강) 또는 `perpendicular_to_axis`(주축에 직각)
- `pick_order` — 높은 것부터. 위에 있는 것을 먼저 집어야 아래가 안 흔들린다
- 파일은 `.tmp` 에 쓴 뒤 원자적으로 교체하므로, 읽는 쪽이 깨진 파일을 보지 않는다

**화면 좌표를 읽을 때**: 검출 박스 위 숫자는 mm 단위 높이이고, 화면 좌표(픽셀)는 ROI·exclude 지정에만 쓴다.
