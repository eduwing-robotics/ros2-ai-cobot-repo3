# FR5 기능 폴더 지도

런타임 구현을 시작할 때 아래 경계로 나눈다. 지금은 폴더 책임만 확정한다.

| 예정 폴더 | 책임 |
|---|---|
| `control/` | 6축 조그·그리퍼·정지·조종권·상태 |
| `teaching/` | 드래그 티칭·지점 저장·재생·레코딩 |
| `slots/` | 로직 슬롯 업로드·버전·차이 비교 |
| `planning/` | 후보 경로·충돌·작업영역·시뮬레이션 결과 검토 |
| `runs/` | 실기/시뮬레이션 실행 기록·비교·재현 정보 |

화면은 브리지나 데이터베이스를 직접 호출하지 않고 `../data/datasource/`만 사용한다.
